# Mission Rewards

A Darktide Mod Framework mod that shows XP and Ordo Docket rewards on mission-board tiles, optional rewards per metre, and character XP progress in the Mourningstar.

## Installation

Install DMF, place the `Mission Rewards` folder in Darktide's mods directory, and add `Mission Rewards` to `mod_load_order.txt`.
